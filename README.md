# ☀️ Solar IoT Monitoring Dashboard (Frontend)

## 📌 Overview
A high-performance, real-time web dashboard designed to manage and monitor Solar IoT nodes. Built with **React** and **Vite**, this frontend application provides operators with immediate visibility into node status, ensuring optimal connectivity and system health. 

This client-side application is seamlessly integrated with a custom Node.js REST API to fetch and display hardware telemetry data without noticeable latency.

> **⚙️ Backend Integration:** This frontend consumes data from its companion backend API. You can explore the backend architecture here: [Backend Segundo Proyecto](https://github.com/samirabarrera/Solar_IoTMonitoring_Backend)

## ✨ Key Features
*   **Real-Time Node Management:** Instantly verify the active/inactive status and health metrics of distributed Solar IoT nodes.
*   **Data Visualization:** Transforms raw telemetry data into intuitive, easy-to-read metrics for quick operational decisions.
*   **High-Speed Rendering:** Utilizes Vite's fast HMR (Hot Module Replacement) and React's virtual DOM to handle frequent data updates smoothly.
*   **Responsive UI:** A clean and accessible interface that allows monitoring from both desktop control centers and mobile devices.

## 🛠️ Tech Stack
*   **Frontend Framework:** React.js
*   **Build Tool:** Vite
*   **Data Visualization:** [Chart.js / Recharts]
*   **HTTP Client:** Axios
